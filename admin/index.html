drag the crosshair to choose what stays in frame
Each photo is cropped to fill a box, and the crosshair decides which part of it survives. The previews on the right are the exact boxes the site uses at each screen size — what you see there is what a visitor sees. Saving writes straight into index.html (a copy of the previous version is kept as index.html.bak), so afterwards just git add -A && git commit && git push.
